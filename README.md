**ARUIYAAA** হলো Termux (Android) এবং Linux টার্মিনালের বোরিং লুক পরিবর্তন করার একটি অটোমেটেড স্ক্রিপ্ট। এটি আপনার টার্মিনালে একটি চমৎকার অ্যানিমেটেড টাইপ-রাইটার ইফেক্ট, লাইভ ডিস্ক স্পেস ট্র্যাকিং, কাস্টম নাম সহ স্টাইলিশ ব্যানার এবং **Oh-My-Zsh** শেলের সাথে প্লাগইন যুক্ত করে সম্পূর্ণ প্রিমিয়াম ও ফিউচারিস্টিক (Cyberpunk) ভাইব এনে দেয়।

---

## ✨ ফিচারসমূহ (Features)

* 🖥️ ডিভাইস ডিটেকশন: Termux এবং Linux সিস্টেম অটো-ডিটেক্ট করে পাথ সেটআপ করে।
* 📊 ডিস্ক ইউজেজ মনিটর: টার্মিনাল চালুর সময় স্টোরেজ ফুল থাকলে ওয়ার্নিং দেখায়।
* ✍️ অ্যানিমেটেড প্রোগ্রেস বার: একটি সুন্দর লোডিং বার এবং টাইপিং ইফেক্ট ইন্ট্রো।
* 🎨 কাস্টম ব্যানার নাম: ইউজার নিজের পছন্দমতো নাম ইনপুট দিয়ে ব্যানার বানাতে পারে।
* ⚡ Zsh + Oh-My-Zsh: অটো-ইনস্টলেশন সহ `autosuggestions` এবং `syntax-highlighting` প্লাগইন সেটআপ।
* 🔤 কাস্টম ফন্ট ও কালার: টার্মিনালের জন্য কাস্টম `font.ttf` এবং গীক কালার স্কিম।

## 🚀 ইনস্টলেশন গাইড (Installation)

# ১. টার্মাক্স আপডেট করে গিট ইনস্টল করুন
pkg update && pkg upgrade -y
pkg install git -y

# ২. গিটহাব থেকে আপনার টুলটি ক্লোন করুন
git clone https://github.com/Aruiyaaa03/ARUIYAAA.git

# ৩. ফোল্ডারে ঢুকে পারমিশন দিয়ে রান করুন
cd ARUIYAAA
chmod +x setup.sh
./setup.sh
